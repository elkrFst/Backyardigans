Dependencias necesarias y opcionales para el sistema Smart Locker

Paquetes requeridos para ejecutar la aplicación:
- opencv-python          # manejo de cámara y procesamiento de imágenes
- Pillow                # conversión y visualización de imágenes en Tkinter
- numpy                 # operaciones numéricas y matrices usadas por OpenCV
- mysql-connector-python# conexión y consulta a MySQL
- gpiozero              # control de GPIO para Raspberry Pi (control de relés de lockers)

Dependencias opcionales (mejoran reconocimiento con la librería real):
- face-recognition       # reconocimiento facial real con dlib (opcional)
- dlib                  # motor de reconocimiento facial requerido por face-recognition

Versiones recomendadas:
- opencv-python: 4.7.x o superior
- Pillow: 10.x o superior
- numpy: 1.26.x o superior
- mysql-connector-python: 8.0.x o superior
- gpiozero: 2.x o superior (solo funciona en Raspberry Pi o con simulación)
- face-recognition: usa la versión compatible con tu Python y dlib
- dlib: versiones compatibles con tu sistema operativo y versión de Python

Notas:
- El proyecto está preparado para funcionar con el fallback de OpenCV (`face_recognition_cv2.py`) si no se instala `face-recognition`.
- gpiozero es requerido para el control de relés de lockers pero se puede ejecutar en simulación si no estás en Raspberry Pi.
- Eliminado el soporte Arduino: `pyserial` ya no es necesario.
- Si usas Python 3.11 o superior, instala las versiones más recientes compatibles de cada paquete.

Control GPIO de Lockers:
- 4 relés conectados a los pines GPIO 17, 27, 22 y 23
- Se activan con active_high=False (señal baja)
- Pulso de apertura: 2 segundos (configurable en config.py)
- Habilitación: mediante variable de entorno GPIO_ENABLED=1
